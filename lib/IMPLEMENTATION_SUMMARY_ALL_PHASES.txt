================================================================================
QUICK SUMMARY
================================================================================

This implementation transforms the Yad-Yad app into a real-time "Waze for prayer 
groups" system where users automatically form prayer groups based on proximity, 
availability, and prayer times - with democratic location voting.

Core Innovation: Minyans form AUTOMATICALLY when 10+ users are available within
a search radius 30 minutes before prayer, eliminating the need for manual creation
while preserving the existing manual minyan feature as a fallback.

What It Does:
├─ Creates voting session when minyan forms
├─ Automatically adds "Central Location" (centroid) as first suggestion
├─ Users can suggest and vote on meeting locations
├─ Shows real-time vote progress with consensus indicator
├─ Auto-detects consensus when majority votes reached
├─ Expires 20 minutes before prayer (auto-finalizes)
└─ Returns winning location for directions/sharing

Key Components:
├─ LocationSuggestion (Entity)
│  ├─ Immutable location data with voting info
│  ├─ Tracks who voted (for single-vote enforcement)
│  ├─ Types: 'centroid', 'synagogue', 'user_suggested'
│  └─ Includes average distance calculation
│
├─ VotingSession (Entity)
│  ├─ Voting context for a minyan
│  ├─ Stores all suggestions sorted by votes
│  ├─ Handles consensus detection: hasConsensus()
│  ├─ Tracks expiry: isExpired(), getMinutesUntilExpiry()
│  └─ Auto-selects leading suggestion: getLeadingSuggestion()
│
├─ CentroidCalculationService (Static Methods)
│  ├─ calculateCentroid(List<GeoPoint>): GeoPoint
│  │  └─ Spherical average (proper for Earth's surface)
│  ├─ calculateDistance(p1, p2): Double (Haversine in km)
│  ├─ calculateAverageDistance(center, points): Double
│  ├─ calculateBoundingBox(points): Map for map bounds
│  └─ formatDistance(km): String (readable format)
│
├─ LocationVotingBloc (State Management)
│  ├─ Events:
│  │  ├─ InitializeVotingSessionEvent
│  │  ├─ AddLocationSuggestionEvent
│  │  ├─ VoteForLocationEvent
│  │  ├─ CheckConsensusEvent (automatic every 10s)
│  │  ├─ FinalizeVotingEvent
│  │  └─ CancelVotingEvent
│  │
│  ├─ States:
│  │  ├─ VotingSessionActive (with time remaining)
│  │  ├─ SuggestionAdded
│  │  ├─ VoteCasted
│  │  ├─ ConsensusReached (winning location included)
│  │  ├─ VotingExpired (auto-selected default)
│  │  └─ LocationVotingError
│  │
│  └─ Key Features:
│     ├─ Automatic expiry timer (30-second checks)
│     ├─ Automatic consensus checks (10-second intervals)
│     ├─ Single-vote-per-user enforcement
│     ├─ Vote changing (overrides previous vote)
│     └─ Proper cleanup: timers canceled in close()
│
├─ LocationSuggestionCard (Widget)
│  ├─ Shows individual location with voting option
│  ├─ Displays:
│  │  ├─ Name, address, type icon (centroid/synagogue/user)
│  │  ├─ Vote count & percentage progress bar
│  │  ├─ Average distance from all participants
│  │  ├─ "Your vote" indicator (filled button)
│  │  └─ "Consensus reached!" badge
│  ├─ Colored border: Blue if user voted
│  └─ Uses AppTheme colors for consistency
│
└─ LocationVotingSheet (Widget)
   ├─ Draggable bottom sheet (50-95% of screen)
   ├─ Shows:
   │  ├─ Header: Title, participant count, time remaining
   │  ├─ Info banner: "Need X votes for consensus"
   │  ├─ Sorted suggestions list (highest votes first)
   │  ├─ "Suggest a Location" button/form
   │  ├─ Finalize button (when consensus or timeout)
   │  └─ Success/Expired screens
   │
   ├─ Handles all LocationVotingBloc states
   ├─ Auto-closes on ConsensusReached
   └─ Returns finalized LocationSuggestion

User Flow (Voting):
